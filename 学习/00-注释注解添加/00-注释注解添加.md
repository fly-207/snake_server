## 说明0

当前项目中的函数全部是被定义在全局范围, 但其实会被 import 导入到一个 _ENV 的环境表中, 然后 import 返回这个环境表

    # 这样做的一个好处是, 在热更新时, 只修要更新 _ENV 中的内容即可, 不存在 upvalue



## 说明1

服务内以 `cmd` 结尾的目录, 都是对外的接口

例如 service\login\logiccmd\login.lua 文件中的函数意义如下

    # 路径 service\login 中的 login 服务

    # service\login\logiccmd\login.lua 中的 login.lua 代表服务会收到一个 login 的模块命令
    
        # login.lua 中 LoginResult/ReadyCloseGS/OnLogout 函数代表会收到对应的具体请求

        # 例如 interactive.Send(".login", "login", "SetOnlinePlayerLimit", {limit = tonumber(iOnlineLimit)})

        # 代表向 .login 服务发送 login 模块发送一个叫做 SetOnlinePlayerLimit 的请求
        
        # 具体会被路由到 service\login\logiccmd\login.lua 中的 SetOnlinePlayerLimit 全局函数来处理
