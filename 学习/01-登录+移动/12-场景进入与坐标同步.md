## 1. 整体流程概览

```
CPlayer:OnLogin()
    └─ CSceneMgr:OnLogin(oPlayer, bReEnter)           [service/world/sceneobj.lua]
        ├─ bReEnter=true  → ReEnterScene              (断线重连，回到原场景)
        └─ bReEnter=false → EnterDurableScene         (首次登录，进入持久化场景)
                └─ CSceneMgr:EnterScene(oPlayer, iScene, {pos})
                    └─ CScene:EnterPlayer(oPlayer, mPos)  [world/sceneobj.lua 代理]
                        ├─ 向客户端发 GS2CShowScene        (world 服务发出)
                        └─ interactive.Send(scene服务, "EnterPlayer", ...)
                            └─ CScene:EnterPlayer(iPid, iEid, mPos, ...) [scene/sceneobj.lua]
                                ├─ 向客户端发 GS2CEnterScene  (scene 服务发出)
                                └─ CScene:Enter(obj)
                                    └─ AoiAction("CreateObject", eid, ...)
                                        → 触发 EnterAoi / LeaveAoi 回调
                                        → 向玩家推送视野内所有实体的 GS2CEnterAoi
```

## 2. world 调度进入场景

### 2.1 `CSceneMgr:OnLogin`

文件：`service/world/sceneobj.lua`  第 295 行

```lua
function CSceneMgr:OnLogin(oPlayer, bReEnter)
    if bReEnter then
        -- 断线重连：玩家的 ActiveCtrl 中记录了上次所在场景
        self:ReEnterScene(oPlayer)
    else
        -- 首次登录（数据加载完成后）：进入持久化大世界场景
        self:EnterDurableScene(oPlayer)
    end
end
```

### 2.2 `CSceneMgr:EnterDurableScene` — 进入持久化场景

```lua
function CSceneMgr:EnterDurableScene(oPlayer)
    -- 读取玩家上次保存的场景/坐标（离线时由 LeavePlayer 写入）
    local mDurableInfo = oPlayer.m_oActiveCtrl:GetDurableSceneInfo()
    local iMapId = mDurableInfo.map_id   -- 地图 ID
    local mPos   = mDurableInfo.pos       -- {x, y, face_x, face_y, ...}

    -- 按地图 ID 选负载最低的 scene 服务实例
    local oScene = self:SelectDurableScene(iMapId)

    self:EnterScene(oPlayer, oScene:GetSceneId(), {pos = mPos})
end
```

**"持久化场景"** 指大世界地图，玩家离线后再登录仍在同一张地图（可能分配到不同的 scene 实例）。

### 2.3 `CSceneMgr:EnterScene` — 通用进入接口

```lua
function CSceneMgr:EnterScene(oPlayer, iScene, mInfo)
    local oNewScene = self:GetScene(iScene)
    assert(oNewScene, ...)

    local oNowScene = oPlayer.m_oActiveCtrl:GetNowScene()
    -- 如果已在某个场景中，先触发离开
    if oNowScene then
        oNowScene:LeavePlayer(oPlayer, false, iScene)
    end
    -- 进入新场景
    oNewScene:EnterPlayer(oPlayer, mInfo.pos, iFromSceneId)
end
```

### 2.4 `CScene:EnterPlayer`（world 侧代理）

文件：`service/world/sceneobj.lua`  第 1135 行

```lua
function CScene:EnterPlayer(oPlayer, mPos, iFromSceneId)
    -- ① 记录玩家当前场景/坐标到 ActiveCtrl（离线存档依赖此值）
    oPlayer.m_oActiveCtrl:SetNowSceneInfo({now_scene=self.m_iSceneId, now_pos=mPos})
    if self:IsDurable() then
        oPlayer.m_oActiveCtrl:SetDurableSceneInfo(self.m_iMapId, mPos)
    end

    -- ② 分配 EntityId（场景内唯一，不是 pid）
    local iEid = self:DispatchEntityId()
    self.m_mPlayers[oPlayer:GetPid()] = iEid

    -- ③ 发给客户端：切换场景 UI 指令
    oPlayer:Send("GS2CShowScene", {
        scene_id   = self.m_iSceneId,
        scene_name = self:GetName(),
        map_id     = self:MapId(),
        x = math.floor(geometry.Cover(mPos.x)),
        y = math.floor(geometry.Cover(mPos.y)),
    })

    -- ④ 跨服务调用：通知远端 scene 服务进行实体创建和 AOI 注册
    interactive.Send(self.m_iRemoteAddr, "scene", "EnterPlayer", {
        scene_id   = self.m_iSceneId,
        eid        = iEid,
        data       = oPlayer:PackSceneInfo(),   -- 玩家在场景中的视觉数据
        pid        = oPlayer:GetPid(),
        pos        = mPos,
        walk_speed = oPlayer:GetWalkSpeed(),
    })

    -- ⑤ 触发 PLAYER_ENTER_SCENE 世界事件（如任务、副本等系统的钩子）
    self:TriggerEvent(gamedefines.EVENT.PLAYER_ENTER_SCENE, {...})
end
```

## 3. scene 服务创建玩家实体


### 3.2 `CScene:EnterPlayer`（scene 侧）

文件：`service/scene/sceneobj.lua`  第 221 行

```lua
function CScene:EnterPlayer(iPid, iEid, mPos, mInfo, iSpeed)
    -- ① 创建 CPlayerEntity 实体对象（仅在 scene 服务内存在）
    local obj = playerobj.NewPlayerEntity(iEid, iPid)
    self.m_mPlayers[iPid] = iEid

    obj:Init({
        scene_id = self:GetSceneId(),
        pos      = mPos,
        speed    = iSpeed,
        data     = mInfo,      -- 包含 name / model_info / show_id 等视觉数据
    })

    -- ② 发给该玩家自身：你已进入场景，附带自身 eid 和精确坐标
    obj:Send("GS2CEnterScene", {
        scene_id = self:GetSceneId(),
        eid      = obj:GetEid(),
        pos_info = {
            v      = geometry.Cover(obj:GetSpeed()),
            x      = geometry.Cover(mPos.x),
            y      = geometry.Cover(mPos.y),
            face_x = geometry.Cover(mPos.face_x or 0),
            face_y = geometry.Cover(mPos.face_y or 0),
        }
    })

    -- ③ 更新共享数据（用于 world 服务读取实时位置）
    obj:UpdateShareData(mPos)

    -- ④ 向 world 广播"玩家进入场景"事件（可用于组队/公会等系统）
    interactive.Send(".world", "scene", "RemoteEvent", {
        event = "player_enter_scene",
        data  = {pid=iPid, scene_id=self:GetSceneId(), ...},
    })

    -- ⑤ 加入 AOI 格子系统（核心：触发视野发现）
    return self:Enter(obj)
end
```

## 4. AOI 系统——视野发现机制

AOI（Area of Interest）实现在 `clib/gaoi/`，由 `CAoiMgr` 封装（`service/scene/aoi/wrapper.lua`）。

### 4.1 `CScene:Enter(obj)` — 注册到 AOI

文件：`service/scene/sceneobj.lua`  第 166 行

```lua
function CScene:Enter(obj)
    self.m_mEntitys[iEid] = obj

    -- 根据实体类型确定 AOI 参数
    if obj:IsPlayer() then
        iWeight = 1
        iType   = 1
        iLimit  = gamedefines.SCENE_PLAYER_SEE_LIMIT  -- 玩家视野上限
    elseif obj:IsNpc() then
        if obj:MonsterFlag() then   -- 怪物/宝箱
            iWeight = 1; iType = 3; iLimit = 0
        else                        -- 普通 NPC
            iWeight = 0; iType = 2; iLimit = 0
        end
    elseif obj:IsEffect() then
        iWeight = 0; iType = 2; iLimit = 0
    end

    -- 向 AOI 系统注册对象，获取 enter/leave 事件列表
    self:AoiAction("CreateObject", iEid, {
        x=mPos.x, y=mPos.y, type=iType, ac_type=iAcType,
        weight=iWeight, limit=iLimit,
    })
end
```

### 4.2 `CScene:AoiAction` — 处理 AOI 事件

```lua
function CScene:AoiAction(sFunc, iEid, ...)
    local oView = self:GetEntity(iEid)
    local mRet  = self.m_oAoi[sFunc](self.m_oAoi, iEid, ...)  -- 调用 C 扩展的 gaoi

    -- 新进入视野的实体对
    for _, k in ipairs(mRet.events.enter) do
        local o = self:GetEntity(k)
        if o then
            oView:EnterAoi(o)   -- 新实体进入 oView 的视野
            o:EnterAoi(oView)   -- oView 进入新实体的视野
        end
    end

    -- 离开视野的实体对
    for _, k in ipairs(mRet.events.leave) do
        local o = self:GetEntity(k)
        if o then
            oView:LeaveAoi(o)
            o:LeaveAoi(oView)
        end
    end
end
```

`gaoi.CreateObject` 由 `clib/gaoi/` 中的 C 扩展实现，返回格子变化后的 `enter` 和 `leave` 实体列表。

### 4.3 玩家侧 `CPlayerEntity:EnterAoi(oMarker)`

```lua
-- 当 oMarker 进入当前玩家视野时被调用
function CPlayerEntity:EnterAoi(oMarker)
    self:OnEnterAoi(oMarker)
end

function CPlayerEntity:OnEnterAoi(oMarker)
    -- 收集 AOI 变化，200ms 后批量发送给客户端（减少频繁小包）
    self:SetAoiAction(0, oMarker:GetEid(), 1)   -- +1 表示进入
end
```

200ms 定时器触发 `HandleAoiAction`，对每个实体计算累计值：
- **累计为 +1**：调用 `OnClientEnter` → 发送 `GS2CEnterAoi`
- **累计为 -1**：调用 `OnClientLeave` → 发送 `GS2CLeaveAoi`

若进入和离开抵消（累计 0），则不发送消息，节省带宽。

## 5. NPC 如何出现在玩家视野

### 5.1 NPC 何时被加入 scene

NPC 在 `scene` 服务启动时或地图初始化时通过 `CScene:EnterNpc(oNpc)` 加入：

```lua
-- service/world/sceneobj.lua
function CScene:EnterNpc(oNpc)
    local iEid = self:DispatchEntityId()
    self.m_mNpc[oNpc.m_ID] = iEid
    -- 通知 scene 服务创建 NPC 实体
    interactive.Send(self.m_iRemoteAddr, "scene", "EnterNpc", {
        scene_id = self.m_iSceneId,
        eid      = iEid,
        pos      = oNpc:PosInfo(),
        data     = oNpc:PackSceneInfo(),
    })
end

-- service/scene/sceneobj.lua
function CScene:EnterNpc(iEid, mPos, mInfo)
    local obj = npcobj.NewNpcEntity(iEid)
    obj:Init({scene_id=..., pos=mPos, speed=0, data=mInfo})
    obj:InitTitle(mInfo.title)
    self:Enter(obj)         -- 注册到 AOI，等待玩家进入视野
    obj:InitMoveAI()        -- 初始化移动 AI（部分 NPC 会巡逻）
end
```

### 5.2 玩家进入时发现 NPC 的触发路径

```
玩家调用 CScene:Enter(playerEntity)
    └─ AoiAction("CreateObject", playerEid, ...)
        └─ gaoi C 扩展计算邻近格子，返回 npcEids 在 enter 列表中
            └─ playerEntity:EnterAoi(npcEntity)     ← 玩家视野中新增 NPC
            └─ npcEntity:EnterAoi(playerEntity)     ← NPC "看到"玩家（用于仇恨等逻辑）
```

### 5.3 `CPlayerEntity:OnClientEnter` — 向客户端推送 NPC 信息

```lua
function CPlayerEntity:OnClientEnter(iType, id)
    local oMarker = oScene:GetEntity(id)
    if oMarker then
        -- 发送 GS2CEnterAoi，包含该实体的完整 AoiInfo
        self:SendRaw(oMarker:GetEnterAoiInfoPack())
    end
end
```

NPC 的 `PackEnterAoiInfo`：

```lua
-- service/scene/npcobj.lua
function CNpcEntity:PackEnterAoiInfo()
    return playersend.PackData("GS2CEnterAoi", {
        scene_id = self:GetSceneId(),
        eid      = self:GetEid(),
        type     = self:Type(),     -- NPC_TYPE = 3 (monster) / 2 (npc)
        aoi_npc  = {
            npctype    = ...,    -- NPC 类型
            func_group = ...,    -- 功能组（宝箱、传送点等）
            npcid      = ...,    -- NPC 配置表 ID
            pos_info   = {x, y, face_x, face_y, v},
            block      = {name, model_info, war_tag, ...},
        },
    })
end
```

客户端收到 `GS2CEnterAoi` 后，根据 `type` 字段区分是玩家还是 NPC，并根据 `npcid` / `model_info` 渲染对应的资源（宝箱的 `func_group` 字段会触发宝箱交互 UI）。

## 6. 客户端收到的消息

进入场景后，客户端将陆续收到以下消息：

| 消息 | 来源服务 | 说明 |
| ---- | -------- | ---- |
| `GS2CShowScene`  | world scene代理 | 切换到指定地图的 UI，显示地图名称和进入坐标 |
| `GS2CEnterScene` | scene | 确认进入场景，附带自身 `eid` 和精确浮点坐标 |
| `GS2CEnterAoi`   | scene（经 playersend 路由） | 视野内每一个实体（其他玩家 / 各类 NPC / 特效）的完整信息 |
| `GS2CSyncAoi`    | scene | 视野内某实体的属性变化（血量、战斗状态等） |
| `GS2CLeaveAoi`   | scene | 某实体离开视野 |

## 7. 坐标同步——玩家移动消息流程

### 7.1 客户端发送移动消息

客户端移动时发送 `C2GSSyncPosQueue`，附带一段移动路径：

```
poslist = [
  {pos={x,y,face_x,face_y}, time=<本段耗时ms>},
  ...
]
```

### 7.2 scene 服务接收并处理

文件：`service/scene/logiccmd/scene.lua`

```lua
function ForwardNetcmds.C2GSSyncPosQueue(oPlayer, mData)
    -- 验证 eid 一致性后缓存移动路径
    oPlayer:CacheSyncPosQueue(mData.poslist or {})
end
```

### 7.3 `CPlayerEntity:CacheSyncPosQueue` — 路径缓存与批处理

文件：`service/scene/playerobj.lua`  第 458 行

```lua
function CPlayerEntity:CacheSyncPosQueue(mQ)
    -- 收集客户端发来的路径点
    for _, v in ipairs(mQ) do
        table.insert(self.m_mCachePosQueue, v)
    end
    -- 500ms 后统一处理（防止频繁小包）
    self:AddTimeCb("DoSyncPosQueue", 500, function()
        oEntity:SyncPosQueue(oEntity.m_mCachePosQueue)
        oEntity:ClrCacheSyncPosQueue()
    end)
end
```

### 7.4 `CPlayerEntity:SyncPosQueue` — 广播位置给 AOI 范围内玩家

```lua
function CPlayerEntity:SyncPosQueue(mQ)
    local mPos = table.remove(mQ, #mQ)  -- 取最新位置
    if mPos then
        -- 向视野内所有玩家广播同步消息（含自身）
        self:SendAoi("GS2CSyncPosQueue", {
            scene_id = self:GetSceneId(),
            eid      = self:GetEid(),
            poslist  = {mPos},
        })
        -- 驱动内部状态机按时间序列重放路径
        self:__SyncPosQueue(mPos)
    end
end
```

### 7.5 `CPlayerEntity:__SyncPosQueue` — 服务器端位置推进

```lua
function CPlayerEntity:__SyncPosQueue(mCurInfo)
    -- 记录当前服务器坐标（用于反外挂校验）
    self:SyncNewPos(gamedefines.RecoverPos(mCurInfo.pos))
    -- 按 time 字段设定定时器，时间到后取下一个路径点继续推进
    local iT = mCurInfo.time
    self:AddTimeCb("__SyncPosQueue", iT, function()
        local mPos = table.remove(oPlayer.m_mPosQueue, 1)
        if mPos then oPlayer:__SyncPosQueue(mPos) end
    end)
end
```

## 8. 其他玩家如何接收到我的坐标更新

### 8.1 `SendAoi` 的实现

```lua
-- service/scene/entityobj.lua
function CEntity:SendAoi(sMessage, mData, bInclude)
    local sData = playersend.PackData(sMessage, mData)
    -- 遍历 AOI 视野内所有玩家实体
    for _, o in ipairs(self:GetAoi(bInclude)) do
        o:SendRaw(sData)
    end
end

function CEntity:GetAoi(bInclude)
    -- 从 gaoi 视野获取 PLAYER_TYPE 实体列表
    for _, k in ipairs(self:GetView(gamedefines.SCENE_ENTITY_TYPE.PLAYER_TYPE)) do
        local o = oScene:GetEntity(k)
        if o then table.insert(lSendObjects, o) end
    end
    if bInclude then table.insert(lSendObjects, self) end
    return lSendObjects
end
```

### 8.2 `SyncNewPos` — 更新 AOI 格位置（触发视野变化）

```lua
-- service/scene/playerobj.lua
function CPlayerEntity:SyncNewPos(mCurPos)
    -- 如果是队伍领队，同步整个队伍视野中的位置
    -- 非领队则自己更新位置
    self:SetPos(mCurPos)   -- → 触发 OnSetPos
end

-- service/scene/entityobj.lua
function CEntity:OnSetPos(x, y)
    -- 通知 AOI 系统位置变化，可能触发新的 enter/leave 事件
    oScene:AoiAction("UpdateObjectPos", self:GetEid(), {x=x, y=y})
end
```

`UpdateObjectPos` 也会返回 `enter/leave` 列表，处理方式与 `CreateObject` 相同——新进视野的实体收到 `GS2CEnterAoi`，离开视野的实体收到 `GS2CLeaveAoi`。

### 8.3 完整移动同步数据流

```
[客户端 A 移动]
    ↓  C2GSSyncPosQueue {poslist=[...]}
[scene 服务]
    CacheSyncPosQueue → SyncPosQueue
        ↓  SendAoi("GS2CSyncPosQueue")     →  视野内玩家 B/C/D 均收到 A 的移动路径
        ↓  __SyncPosQueue → SyncNewPos → AoiAction("UpdateObjectPos")
            ↓  如果玩家 A 移动导致玩家 E 进入/离开视野：
               玩家 A 收到 GS2CEnterAoi/GS2CLeaveAoi（E 的信息）
               玩家 E 收到 GS2CEnterAoi/GS2CLeaveAoi（A 的信息）
```
